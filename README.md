# AI-Hallucination-Detector-System 

An advanced AI-powered system to detect hallucinations in Large Language Models (LLMs) by comparing generated responses with trusted sources and multiple AI models.

## Features

- Multi-model AI response comparison
- Hallucination detection using similarity analysis
- Sentence embeddings with cosine similarity
- Natural Language Inference (NLI) verification
- Trusted evidence checking from Wikipedia and web sources
- Confidence score generation
- Interactive dashboard for analysis

## Technologies Used

- Python
- Streamlit
- Sentence Transformers
- Hugging Face Models
- Scikit-learn
- Wikipedia 
- Groq API
- Gemini API
- Cerabras API
- Cloudflare API
- Mistral API
